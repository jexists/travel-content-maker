## 항목별 체크리스트

### 0. 업무명
- [ ] 업무명 확정 (안: **여행 콘텐츠 3채널 제작·컨펌 업무**)
- [ ] 한 줄 정의와 발표 문장
- [ ] 대표·매니저는 가상 역할이라는 설명

### 1. 현재 업무 분석
- [ ] As-Is 맵 이미지 + Draw.io 원본 링크
- [ ] 단계표 A01~A14 (담당·도구·근거)
- [ ] 문서·데이터 목록 D1~D8
- [ ] 문제 카드 P1~P6
- [ ] 최소 기준선 (미확인은 측정 계획과 함께)

### 2. 개선 설계
- [ ] 무엇을 어떻게 바꾸는지 (문제별 개선 방향)
- [ ] 1안 선택 이유 + 2·3안 비교
- [ ] To-Be 맵 이미지 + 단계표 T01~T14
- [ ] AI·시스템·사람 역할표, RACI
- [ ] 요구사항: 기능·비기능·게시 규칙·수용 기준

### 3. 시스템
- [ ] 구성도 이미지 + Draw.io 원본 링크
- [ ] 실제 만든 스킬·스크립트 파일 목록과 역할
- [ ] 폴더 구조와 콘텐츠대장 열 구성
- [ ] 상태 흐름·버전 규칙·실패 처리

### 4. 실행 방법
- [ ] 준비물과 설치
- [ ] 예제 입력 (`input/C-001/` 사진 + `memo.md`)
- [ ] 실행 문장 예시와 순서
- [ ] 결과 파일 위치 (`output/C-001/<채널>/vN/`, `ledger.xlsx`)
- [ ] 재실행·반려 시 이전 기록이 남는지 확인하는 법
- [ ] 작동한 기능 / 남은 문제
- [ ] API 키·개인정보가 들어가지 않았는지 확인

## 발표(시연) 순서와 연결

1. 업무명 + 현재 업무와 문제 (0·1)
2. 개선 흐름과 선택안 (2)
3. 시스템 구성 (3)
4. 시연: 사진 입력 → 인스타 → 매니저 반려 1회 → v2 컨펌 → 유튜브 → 티스토리 → 대표 승인 → 대장 확인 (4)
