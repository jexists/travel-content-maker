## 2. 개선 설계 (To-Be)

> 2026-11-10 구현 기준으로 고침: 매니저 역할 없음(중간 단계는 에디터 확인), 대표는 세 채널 배포 직전 1회, 질문은 확인 지점 A~E, 결과는 `work/C-xxx_장소/`. 흐름도는 [03 업무흐름도](03_업무흐름도.md) 2장.

### 2-2. 선택한 안 — 1안 · Claude 스킬 + 로컬 파일

| 비교 | 1안 스킬 + 로컬 ✅ | 2안 Notion/Sheets + 자동화 | 3안 자체 프로그램 + API |
| --- | --- | --- | --- |
| 사진 폴더 처리 | 바로 읽음 | 업로드·연동 필요 | 가능 |
| 카드 PNG·숏폼 생성 | 로컬 도구(Chrome·ffmpeg)로 가능 | 어려움 | 가능 |
| 채널별 컨펌 | 대화에서 바로 입력 | 체크박스로 가능 | 화면 개발 필요 |
| 비용·키 | 없음 | 없음 | API 키·사용료 |
| 하루 안 구현 | 가능 | 이미지·영상에서 막힘 | 빠듯함 |

**선택 이유**: 입력이 로컬 사진이고 결과가 이미지·영상·글 파일이라 파일을 직접 다루는 1안이 가장 자연스럽다. 컨펌·반려를 대화에서 바로 입력할 수 있고 추가 비용이 없다. 대장을 Excel로 두면 나중에 실제 팀이 생겼을 때 2안(Sheets·Notion)으로 옮기기 쉽다.

## 부록. 협찬 흐름 조사 (확장 아이디어)

이번 범위에서는 제외했지만 다음 단계로 확장할 때 참고한다. 모두 조사 기반 가설(H).

- 시작은 **체험단 플랫폼 신청**(광고주 공고 → 신청 → 선정) 또는 **직접 제안**(제안서 + 레퍼런스 전송). 경험이 없으면 체험단으로 포트폴리오를 쌓은 뒤 제안하는 순서가 권장된다.
- 선정 후: 조건 협의 → 가이드라인(필수 키워드·해시태그·사진 장수·금지 표현·기한) → 방문 → 원고 → 광고주 검수·수정 → 게시 → 결과 보고.
- 무료 제공·원고료 등 **경제적 이해관계는 반드시 표시** (공정위 추천·보증 심사지침). 블로그는 본문 처음 또는 끝, 사진 SNS는 사진 안, 동영상은 제목 또는 시작·끝. "광고·협찬·유료 광고"처럼 알아보기 쉬운 한국어로. ⚠️ 언론 보도 기준, 원문 확인 필요.
