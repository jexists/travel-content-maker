03 OpenAI API 키 — 선택

make_shorts.openai_key() · 환경변수 OPENAI_API_KEY
캡처 필요platform.openai.com/api-keys — 로그인 후 화면이라 직접 캡처하지 못함
  1. platform.openai.com 로그인
  2. API keys → Create new secret key
  3. 나온 키를 복사 (다시 볼 수 없음)
  4. 04단계의 .env에 붙여 넣기
  • 키 없으면 · macOS say(Yuna)로 대체 + check.md에 표시
  • 키는 채팅·.env.example·제출 파일에 넣지 않기
