# 예제 입력

`가우도/` — 전남 강진 가우도 사진 7장 (2025-05-05 촬영). 긴 변 2048px, **GPS·EXIF를 지운 복사본**이다(원본은 제출하지 않음).

- P001 웰컴 가우도 안내판 · P002 액자 포토존 · P003 출렁다리 · P004 GAUDO 조형물 · P005 섬 안내도 · P006 청자타워 · P007 출렁다리 통행 안내판
- 20장 이하라 `insta-pick`이 고르지 않고 전부 쓴다.
- EXIF를 지워 촬영 시각이 없으므로 순서는 파일 이름순이다. 실제 실행 예시(C-001·C-002)는 원본 폴더로 만들었고, 블로그의 "5월 5일 오전" 같은 시각은 원본 촬영 시각에서 가져왔다.

실행 예: Claude Code에서 `examples/가우도 사진으로 여행 콘텐츠 만들어줘. 장소는 가우도` (자세한 순서는 루트 README).
