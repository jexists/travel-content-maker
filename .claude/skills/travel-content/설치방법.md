# travel-content 설치 (Mac · Windows)

여행 사진 폴더로 인스타 카드뉴스 · 유튜브 숏폼 · 티스토리 블로그를 만드는 Claude 스킬이에요. **4단계면 끝나요.**

| 단계 | Mac | Windows |
| --- | --- | --- |
| **① 앱 설치** | [Claude 데스크톱 앱](https://claude.ai/download)을 설치하고 로그인 (Code 탭 사용) | 같음 |
| **② 스킬 넣기** | 받은 zip을 풀어 `travel-content` 폴더를<br>`~/.claude/skills/` 안에 넣기<br>(Finder에서 ⌘⇧G → `~/.claude/skills` 입력, skills 폴더가 없으면 새로 만들기) | 받은 zip을 풀어 `travel-content` 폴더를<br>`C:\Users\<내 이름>\.claude\skills\` 안에 넣기<br>(탐색기 주소창에 `%USERPROFILE%\.claude\skills` 입력, skills 폴더가 없으면 새로 만들기) |
| **③ 목소리 키 넣기** | [platform.openai.com](https://platform.openai.com/api-keys) → API keys → Create new secret key<br>`travel-content` 폴더 안 `.env.example`을 복사해 이름을 `.env`로 → 텍스트 편집기로 열어 `OPENAI_API_KEY=` 뒤에 키 붙여 넣고 저장<br>(Finder에서 ⌘⇧. 로 숨김 파일 보기) | 같음<br>(탐색기 보기 → 파일 확장명 켜기 — `.env.txt`가 되지 않게, 메모장으로 열기) |
| **④ 쓰기** | Claude 앱 Code 탭에서 사진이 있는 폴더를 열고<br>**"이 사진으로 여행 콘텐츠 만들어줘. 장소는 ○○"** | 같음 |

- **Python은 따로 안 깔아도 돼요.** 처음 쓸 때 Claude가 Python(3.10 이상)·필요한 프로그램·ffmpeg를 확인하고 없으면 설치해요(명령 실행 승인만 눌러 주세요). 직접 깔고 싶으면 [python.org](https://www.python.org/downloads/) — Windows는 설치 첫 화면에서 **Add python.exe to PATH** 체크.
- 처음 쓸 때 Claude가 준비를 알아서 해요. 설치 중 문제가 나면 Claude가 원인을 보고 바로 고치고, 로그인·실행 승인처럼 사람이 해야 하는 것만 부탁해요.
- Claude Code는 유료 계정(Pro·Max·Team 등)이 필요해요.
- 터미널을 쓰는 분은 Claude Code를 `curl -fsSL https://claude.ai/install.sh | bash`(Mac) / `irm https://claude.ai/install.ps1 | iex`(Windows PowerShell)로 설치해도 돼요.

## 목소리 키 (③) 더 알기
- 괜찮은 숏폼 목소리(OpenAI `gpt-4o-mini-tts`)에 필요해요. OpenAI API는 결제 수단을 등록해야 하고, 쓴 만큼만 과금돼요(같은 문장은 저장해 두고 다시 과금하지 않아요).
- `.env`는 스킬 폴더에 한 번 넣으면 모든 사진 폴더에 적용돼요. 사진 폴더에 따로 넣어도 돼요.
- 키가 없어도 만들어지긴 해요 — Mac은 기본 한국어 음성(Yuna), Windows는 설치된 한국어 음성. 대신 기계 같은 목소리예요.
- 키는 채팅에 붙여 넣지 말고, 이 스킬을 다른 사람에게 보낼 때 `.env`는 빼고 보내세요.

## 쓰는 법
Claude가 다섯 번만 물어봐요. 한 메시지로 답하면 돼요.

| 지점 | 보는 것 | 답 예시 |
| --- | --- | --- |
| A | 사진 순서(1번=표지) · 표지 문구 · 캡션 · 찾은 정보 | `이대로` / 고칠 것 / `내가 고를게` |
| B | 영상 제목 · 장면별 대본 | `이대로` / 고칠 문장 |
| C | 블로그 제목 후보 5개 · 미리보기 | `2번 제목으로 이대로` |
| D | 세 채널 최종 확인 | `대표 승인 전부` |
| E | 올린 뒤 게시 링크 | 링크 세 개 한 번에 |

결과는 작업 폴더의 `work/C-001_장소/` 안 `instagram/` · `youtube/` · `tistory/`에 생기고, `OUTPUTS.md`에서 한 번에 열 수 있어요.
