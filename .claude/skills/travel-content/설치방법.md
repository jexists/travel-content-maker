# travel-content 설치 (Mac · Windows)

여행 사진 폴더로 인스타 카드뉴스 · 유튜브 숏폼 · 티스토리 블로그를 만드는 Claude 스킬이에요. **3단계면 끝나요.**

| 단계 | Mac | Windows |
| --- | --- | --- |
| **① 앱 설치** | [Claude 데스크톱 앱](https://claude.ai/download)을 설치하고 로그인 (Code 탭 사용)<br>Python 3.10 이상: [python.org](https://www.python.org/downloads/) | [Claude 데스크톱 앱](https://claude.ai/download)을 설치하고 로그인 (Code 탭 사용)<br>Python 3.10 이상: [python.org](https://www.python.org/downloads/) — 설치 첫 화면에서 **Add python.exe to PATH** 체크 |
| **② 스킬 넣기** | 받은 zip을 풀어 `travel-content` 폴더를<br>`~/.claude/skills/` 안에 넣기<br>(Finder에서 ⌘⇧G → `~/.claude/skills` 입력) | 받은 zip을 풀어 `travel-content` 폴더를<br>`C:\Users\<내 이름>\.claude\skills\` 안에 넣기<br>(탐색기 주소창에 `%USERPROFILE%\.claude\skills` 입력) |
| **③ 쓰기** | Claude 앱 Code 탭에서 사진이 있는 폴더를 열고<br>**"이 사진으로 여행 콘텐츠 만들어줘. 장소는 ○○"** | 같음 |

- 처음 쓸 때 Claude가 준비(필요한 프로그램·ffmpeg 설치)를 알아서 해요. 설치 중 문제가 나면 Claude가 원인을 보고 바로 고치고, Python 설치·로그인·관리자 권한처럼 사람이 해야 하는 것만 부탁해요.
- Claude Code는 유료 계정(Pro·Max·Team 등)이 필요해요.
- 터미널을 쓰는 분은 Claude Code를 `curl -fsSL https://claude.ai/install.sh | bash`(Mac) / `irm https://claude.ai/install.ps1 | iex`(Windows PowerShell)로 설치해도 돼요.

## 선택 · 더 자연스러운 목소리
작업 폴더(사진 폴더)에 `.env` 파일을 만들고 한 줄 넣으면 숏폼 내레이션이 OpenAI 목소리가 돼요.
```
OPENAI_API_KEY=sk-...
```
없으면 Mac은 기본 한국어 음성(Yuna), Windows는 설치된 한국어 음성을 써요. 키는 채팅에 붙여 넣지 마세요.

## 쓰는 법
Claude가 다섯 번만 물어봐요. 한 메시지로 답하면 돼요.

| 지점 | 보는 것 | 답 예시 |
| --- | --- | --- |
| A | 사진 순서(1번=표지) · 표지 문구 · 캡션 · 찾은 정보 | `이대로` / 고칠 것 / `내가 고를게` |
| B | 영상 제목 · 장면별 대본 | `이대로` / 고칠 문장 |
| C | 블로그 제목 후보 5개 · 미리보기 | `2번 제목으로 이대로` |
| D | 세 채널 최종 확인 | `대표 승인 전부` |
| E | 올린 뒤 게시 링크 | 링크 세 개 한 번에 |

결과는 작업 폴더의 `work/C-001_장소/` 안 `instagram/` · `youtube/` · `tistory/`에 생기고, `OUTPUTS.md`에서 한 번에 열 수 있어요.
