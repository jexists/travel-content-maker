# 티스토리 블로그 글 (content.tistory)

먼저 `common.md`. 참고: jexists/plog 글쓰기 규칙(후기형·문단·사실 확인)을 티스토리 HTML에 맞게 옮김.

## 형식
```json
"tistory": {
  "title": "메인 키워드로 시작, 40자 이하",
  "intro": "첫 문단. 메인 키워드 포함, 왜 갔고 어떤 곳인지 2~3문장",
  "sections": [
    {"h2": "출렁다리 건너 가우도로", "alt": "강진 가우도 출렁다리",
     "blocks": [
       {"text": "사진 앞 문단 — 이 장면으로 들어가는 이야기"},
       {"photo": "01_P001.jpg", "caption": "선택. 짧은 설명"},
       {"text": "사진에서 보이는 것을 이어서 설명"},
       {"photo": "02_P002.jpg"}
     ]}
  ],
  "tags": ["…"], "outro": "마무리 문단"
}
```
- `blocks`는 적힌 순서대로 글에 들어간다. 옛 형식(`photos` + `text`)도 동작하지만 새 글은 `blocks`로 쓴다.
- 사진 파일명은 `best_tistory/` 이름 그대로. **01번부터 순서대로, 모든 사진을 한 번씩** 쓴다 (점검 항목).
- 사진은 연속 최대 2장(`settings.blog.max_consecutive_photos`). 소제목마다 문단이 최소 1개 있어야 한다.
- 대표 이미지는 01번 사진(`settings.blog.cover_photo_index`). 대표로 쓰기 좋은 사진이 01번이 되도록 사진 단계에서 정한다.
- 기본 정보 표(info)와 숏폼 링크는 스크립트가 붙인다. 본문에 다시 쓰지 않는다.

## 글쓰기
- 설명문이 아니라 직접 다녀온 사람이 순서대로 정리한 후기. 흐름: 도착 → 장면별 경험 → 정보·팁 → 마무리.
- 문단은 2~4문장. 한 문장짜리 문단만 이어 붙이지 않는다. 개조식(1. 2. 3.) 나열 금지 — 정보는 표·팁 목록에 맡긴다.
- 모든 문장을 "~입니다/~해요"로 똑같이 끝내지 않는다. 관찰("물이 빠져 갯벌이 넓게 드러나 있었어요"), 이동("다리를 다 건너면"), 생각("사진으로 보던 것보다 다리가 길었어요" — 사용자가 말한 경우만)을 섞는다.
- 연결어를 자연스럽게: "다리를 건너면", "조금 더 걸어가면", "그래서", "반대로". 같은 연결어를 반복하지 않는다.
- 사진마다 그 사진에 실제로 보이는 것과 연결한다. 사진과 상관없는 일반 정보(지역 역사 등)를 끼워 넣지 않는다.
- 사진 바로 뒤 문단은 그 사진을 이어 받는다. 정보 사진(안내도·수칙 안내판)은 "안내도를 보면"처럼 읽은 내용을 쓰고 출처가 안내판임을 밝힌다.
- 사용자 메모에 감상이 없으면 감상을 지어내지 않는다. 대신 장면을 구체적으로 묘사한다.
- 마무리는 짧게: 준비물·시간대 같은 실용 팁 1~2개 + 확인 필요 안내. "다음에 또 오고 싶다" 같은 상투적 문장은 쓰지 않는다.

## 다시 쓰기
- 매니저 반려 사유가 "제목"이면 title만, "본문"이면 해당 섹션 blocks의 text만 고친다. 사진 배치는 사진 문제일 때만 바꾼다.
