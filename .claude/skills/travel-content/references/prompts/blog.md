# 티스토리 블로그 글 (content.tistory)

**글 쓰는 기준은 [`blog_plog.md`](blog_plog.md) — jexists/plog 프롬프트 원문(공통 + 여행 + 제목·태그 + AI 리뷰)을 그대로 따른다.** 이 파일은 그 원문을 이 스킬의 형식(`blocks`)에 넣는 방법과, 원문과 다르게 적용할 곳만 적는다. 먼저 `common.md`.

## 순서
1. `blog_plog.md` 1(공통)·2(여행)·3(작성 지시)대로 본문을 쓴다 → 아래 형식의 `intro`·`sections`·`outro`.
2. `blog_plog.md` 4대로 제목 후보 10개(`title_candidates`)와 태그를 만들고, 그중 하나를 `title`로 고른다.
3. `blog_plog.md` 5(AI 리뷰)를 본문에 한 번 적용한다(맞춤법·반복 표현만, 내용 추가 금지).
4. `tc.py build --ch tistory` → 점검 실패 항목을 고친다.

## 형식
```json
"tistory": {
  "title": "강진 가우도 여행 코스 출렁다리 건너 섬 한 바퀴 후기",
  "title_candidates": ["…10개…"],
  "intro": "도입: 여행을 가게 된 계기 / 첫인상 / 어떤 경험을 할 수 있는지. 메인 키워드 포함",
  "sections": [
    {"h2": "위치 및 방문 방법", "alt": "강진 가우도 출렁다리",
     "blocks": [
       {"text": "문단 2~3줄"},
       {"photo": "01_P003.jpg", "caption": "선택. 짧은 설명"},
       {"text": "사진에서 이어지는 문단"}
     ]},
    {"h2": "여행지 분위기", "blocks": ["…"]},
    {"h2": "추천 코스", "blocks": ["…"]},
    {"h2": "방문 팁", "blocks": ["…"]}
  ],
  "tags": ["강진가우도", "강진 가우도", "…"],
  "outro": "마무리: 여행 총평 / 추천 대상 / 방문 추천 이유"
}
```
- 소제목은 plog 여행 구조(위치 및 방문 방법 → 여행지 분위기 → 추천 코스 → 방문 팁)를 따르되, 원문대로 "항목처럼 나열하지 말고" 실제 여행 흐름 속에서 자연스럽게 이름을 붙인다(예: "출렁다리 건너 가우도로").
- `blocks`는 적힌 순서대로 글에 들어간다. 사진 파일명은 `best_tistory/` 이름 그대로 **01번부터 순서대로, 모든 사진을 한 번씩**(원문 "누락 금지"). 사진 연속 최대 2장, 소제목마다 문단 1개 이상.
- 대표 이미지는 01번 사진. 본문 끝 정보 정리(주소·주차·입장료·촬영일)는 스크립트가 `info` 표로 붙인다 — 본문에 다시 쓰지 않는다.
- 본문 text에는 마크다운 기호를 쓰지 않는다(원문 리뷰 규칙).

## 점검 항목 (rules.json `tistory`, plog 원문 수치)
- 본문(intro + 문단 + outro, 공백 제외 아님) **1500자 이상**
- 메인 키워드(`seo.main`) 본문 **5~7회**
- 제목 **25~35자**, 메인 키워드로 시작
- 태그 5~10개(원문 15개 → 티스토리 기준으로 줄임), 메인 키워드 태그 포함

## 원문과 다르게 적용하는 곳 (처음 요청 원칙 우선)
- "실제로 방문한 것처럼", "감정이나 개인적인 느낌을 적절히 포함"은 **사용자가 실제로 다녀온 여행**이라 후기 말투(~인 것 같다, 생각보다, 개인적으로는)로 쓴다. 단 사용자가 말하지 않은 감정·맛·대기시간·동행 같은 사실은 지어내지 않는다. 사진에 보이는 것(물 빠진 갯벌, 흐린 하늘)과 사용자 메모를 근거로 쓴다.
- "운영시간 / 입장료"는 `info`에 출처가 있는 값만, 나머지는 원문대로 "방문 전 확인".
- 원문 "네이버 블로그"는 티스토리로 읽는다.

## 다시 쓰기
- 반려 사유가 "제목"이면 `title`만(후보에서 다시 고르거나 새로), "본문"이면 해당 섹션 `blocks`의 text만 고친다. 사진 배치는 사진 문제일 때만 바꾼다.
