# 인스타그램 (content.instagram)

먼저 `common.md`. 디자인 기준: jexists/instpic 첫 장 (`settings.json`의 `instagram.brand`).

## 형식
```json
"instagram": {
  "cover_title": "가우도",
  "cards": [{"photo": "01_cover_P003.jpg"}, {"photo": "02_P001.jpg"}, …],
  "caption": "…", "hashtags": ["#강진가우도", …]
}
```
- `cards`는 `best_insta/` 파일 순서 그대로(01, 02, …). 순서를 바꾸지 않는다(점검 항목).
- **첫 장만 글자**: 위 `#지역 #동네`(region 2개, 손글씨·밑줄) + 아래 `cover_title`(장소명, 몬소리체). 한 줄로 들어가게 짧게 — 장소명 2~6자 권장. 설명 문장·대본을 표지에 쓰지 않는다.
- **2장부터 원본 사진만**. 카드에 `text`를 쓰지 않는다. 사용자가 특정 카드에 문구를 원하면 그 카드에만 `"text": "…", "force_text": true`. 모든 카드에 문구를 켜려면 작업폴더 `settings.json`에 `{"instagram": {"text_on_other_images": true}}`.
- 사진 비율은 원본 그대로(자르지 않음). 비율이 섞이면 check.md에 경고가 나온다.

## 캡션
- 첫 줄: 장소를 알 수 있는 짧은 한 줄(메인 키워드 포함 권장). 이모지는 줄 머리에 1~2개까지.
- 본문 2~4줄: 사진 순서대로 무엇을 볼 수 있는지. 과장·광고 문구 없이.
- 정보 줄(📍 위치, 🚶 코스 등)은 확인된 것만. 요금·시간은 "방문 전 확인".
- 해시태그 5~15개: 메인 키워드 붙여 쓰기(#강진가우도) → 장소 → 지역+여행 → 카테고리. 같은 뜻 중복 금지.
