# 유튜브 숏폼 대본 (content.youtube.script)

먼저 `common.md`. 참고: smartdong-2team/blog2shorts 장면 구조(hook·body·cta), 해요체, 자막 분할 방식.

## 형식
```json
"youtube": {
  "title": "…#shorts", "description": "…", "tags": ["…"],
  "script": {
    "hook_text": "강진에 이런 섬이 있다고?",
    "pronounce": {"GAUDO": "가우도"},
    "scenes": [
      {"photo": "cover", "role": "hook", "narration": "다리를 걸어서만 들어갈 수 있는 섬, 강진 가우도예요."},
      {"photo": "P001", "role": "body", "narration": "…", "subtitle": "선택 — 화면 자막을 다르게 쓸 때만"},
      {"photo": "P005", "role": "cta", "narration": "…"}
    ]
  }
}
```
- `photo`: `"cover"`(인스타 표지 **사진**을 화면 가득, 첫 장면 권장) 또는 사진 ID. 사진은 확정된 인스타 순서대로만 쓴다(점검 항목). 장면마다 다른 사진.
- `hook_text`: 화면 위쪽에 **영상 내내 고정**되는 훅 문구(15자 안팎, 1~2줄). 장소가 바로 드러나거나 궁금하게 만드는 한 줄.
- `role`: 첫 장면 `hook`, 마지막 `cta`, 나머지 `body`.
- 장면 5~8개, **한 장면 한 문장**(10~25자), 내레이션 합계 110~170자 → 약 15~25초(규칙 15~30초). 장면 길이는 TTS 실제 길이로 자동으로 정해진다(짧은 문장 = 빠른 컷).
- `subtitle`은 화면 글자를 짧게 줄이고 싶을 때만 쓴다. **문장 수가 narration과 같아야 하고 뜻이 같아야 한다.**
- `pronounce`: 영어·약어를 TTS가 이상하게 읽으면 발음을 적는다(자막에는 원문). 숫자·단위(2.5km, 1시간, 1~2월)는 스크립트가 자동으로 읽기 쉽게 바꾼다.

## 대본 쓰기 — 요즘 여행 릴스 방식 (2026 조사, 아래 출처)
목표: 보는 사람이 "여기 가 보고 싶다"고 느끼고 **저장**하게 만든다. (저장·공유가 좋아요보다 강한 신호, 완주율이 중요)

- **첫 1~2초 = 훅**: 가장 강한 장면(표지 사진) + 위쪽 `hook_text` + 첫 문장. 장소 이름을 2초 안에 말한다.
  - 쓸 수 있는 훅 유형: 궁금증("강진에 이런 섬이 있다고?"), 반전·조건("차로는 못 가요. 걸어서만 들어가는 섬"), 리스트("가우도에서 꼭 할 3가지"), 내부자 팁("주차는 저두 쪽이 편해요" — 확인된 정보만), 비교("사람 많은 섬 말고, 여기").
  - 금지: 사실이 아닌 과장("한국의 몰디브", "역대급"), 구독·좋아요 구걸.
- **본문 = 장면마다 한 문장, 장면에 보이는 것 하나**: "물 빠진 갯벌 위로 다리가 쭉 이어져요"처럼 눈에 보이는 장면을 감각적으로. 설명문 말고 친구에게 말하듯. 같은 어미를 연달아 쓰지 않는다(…요/…거든요/…예요/질문형 섞기).
- **화면 글자로 남길 정보**: 장소명·거리·소요시간처럼 캡처하고 싶은 정보는 자막에 그대로 보이게(숫자 그대로).
- **마지막 = 저장 유도 + 실용 한 줄**: "섬 한 바퀴 2.5km, 한 시간이면 돼요. 저장해 두고 주말에 가 보세요." 요금·시간처럼 바뀌는 숫자는 말하지 않고 "가기 전에 확인".
- 모든 문장 해요체, 느낌표·이모지 없음(TTS가 어색해짐). 블로그 글을 줄이지 말고 따로 쓴다.
- 음악: 스크립트는 음악을 넣지 않는다. 인스타·유튜브 앱에서 업로드할 때 **트렌드 음원을 작게** 깔면 된다(내레이션 유지).

## TTS (목소리)
- 기본 `settings.json` → `shorts.engine: "openai"`, `gpt-4o-mini-tts`, 목소리 `marin`, `instructions`로 톤 지정(밝고 설레는 친구 추천 톤, 과장 금지, 약간 빠르게).
- 키: 환경변수 `OPENAI_API_KEY` 또는 프로젝트 루트 `.env`(`OPENAI_API_KEY=…`, git 제외). 키가 없으면 macOS `say`로 만들고 check.md에 "예비 엔진"이라고 남는다 — 그 영상을 OpenAI 목소리라고 말하지 않는다.
- 같은 문장·설정은 `_cache/tts/`에 저장해 다시 만들 때 과금하지 않는다.
- OpenAI 문서 기준 `gpt-4o-mini-tts`는 2027-01-06 종료 예정 → 그 전에 모델 교체 필요.
